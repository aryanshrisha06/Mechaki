
# Zone Rush Bot V5

A Python strategy bot for the Zone Rush competition. V5 combines territory expansion, cell capture, raids, upgrades, opponent tracking, and defensive shielding.

## Files

| File | Description |
|---|---|
| `bot.py` | Main competition bot |
| `bot_v5.py` | V5 development copy |
| `benchmark_v5.py` | Benchmark runner against the local simulator |
| `simulator.py` | Local game simulator |

## Strategy Overview

### 1. Territory Expansion
- Uses pathfinding to identify reachable cells.
- Prioritises valuable neutral territory.
- Considers travel distance and remaining game turns.
- Avoids occupied cells.

### 2. Raiding
- Evaluates rival-owned cells based on their point value.
- Considers raid bonuses and the income denied to opponents.
- Gives additional consideration to cells owned by the current leader.

### 3. Cell Upgrades
- Evaluates whether upgrading an owned cell is worthwhile.
- Considers the additional income generated by upgraded cells.
- Balances upgrades against opportunities to capture new territory.

### 4. Defensive Shielding
- Tracks rival activity on owned territory.
- Uses SHIELD when a valuable cell is at risk of capture.
- Tracks shield cooldowns to avoid unnecessary use.

### 5. Adaptive Decision-Making
- Tracks previous actions and positions.
- Maintains target preferences to reduce unnecessary movement.
- Estimates opponent scores and movement patterns.
- Uses a fallback action if no suitable target is available.

```powershell
python test_bot.py
```

## Running the Benchmark

Run:

```powershell
python benchmark_v5.py
```

The benchmark evaluates the bot against the existing simulator opponents across 100 games, rotating the bot through all four starting positions.

It reports:
- Wins, draws and losses
- Win percentage
- Average bot score
- Average opponent score
- Average score difference
- Performance by starting position

**Note:** Local benchmark results are not official competition results. Performance may differ against the official game engine and other submitted bots.
